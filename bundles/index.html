Bundles & sticks detection

Computer vision · object detection

A trained model watches a recorded lesson and counts place-value materials: bundles (tens) and single sticks (ones). This clip is the model's own annotated output.

The Concept

Teachers use bundles and sticks to support the conceptual development of place value. Students' mathematical language is suppoorted by the use of materials. As a student determines a given quantity, the model records their strategy and compares that thinking with the actual amount. LessonLift can tell whether a child is counting every stick by ones or understands the significance of the group of tens - a real difference in place value understanding.

What you're seeing

The model draws a box around each object it finds and labels it a bundle or a stick, then tallies each.

How it was built

A custom detection model trained on labeled example images (supervised learning). Every teacher confirmation can become a new labeled example, so the model adapts to a classroom's own materials over time.
